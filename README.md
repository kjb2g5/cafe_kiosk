# 클래스와 객체 기반의 카페 키오스크 주문 시스템

파이썬의 객체 지향 프로그래밍 원칙을 적용하여, 음료와 디저트를 선택해 장바구니에 담고 최종 결제 금액과 영수증을 출력하는 키오스크 프로그램입니다.

## 주요 클래스 설계

### 1. `MenuItem` 클래스
- **역할:** 카페의 개별 메뉴(음료 및 디저트) 정보를 표현합니다.
- **속성:** `name` (메뉴명), `price` (가격), `is_ice` (온도 옵션: `True`=ICE, `False`=HOT, `None`=디저트)
- **기능:** `get_info()`, `__str__()` — 메뉴명, 온도 옵션, 천 단위 쉼표가 적용된 가격 문자열 반환

### 2. `Order` (장바구니) 클래스
- **역할:** 손님의 장바구니 관리, 총액 계산, 영수증 출력을 담당합니다.
- **속성:** `items` (`MenuItem` 객체들을 저장하는 리스트)
- **기능:**
  - `add_item(menu_item)`: 장바구니에 `MenuItem` 객체 추가
  - `get_total_price()`: 담긴 모든 메뉴 객체의 가격 합산 반환
  - `print_receipt()`: 전체 주문 내역, 총 수량, 최종 결제 금액 영수증 출력
